# Logos (Bible RAG) 📖✨

> **Полностью автономное (100% Offline) мобильное приложение для чтения Священного Писания с гибридным семантическим поиском и ИИ-собеседником «Писарь Соломона».**

---

## 🌟 Ключевые возможности

1. **Аутентичный цифровой ридер Библии (Logos)**:
   - Эстетика антикварного кожаного переплёта, золотого тиснения и пергамента.
   - Реалистичная 3D-анимация перелистывания страниц книги (`HorizontalPager` + `graphicsLayer`).
   - Иерархическое книжное оглавление: разделы Заветов («Ветхий Завет», «Новый Завет»), раскрывающиеся книги со сквозной нумерацией страниц и отступами для подглав.
   - Автоматическое сохранение прочитанной страницы и мгновенное продолжение чтения.

2. **Высокопроизводительное C++ ядро (On-Device RAG)**:
   - **Лексический поиск**: SQLite FTS5 (полнотекстовый поиск по 31 102 стихам Синодального перевода).
   - **Семантический поиск**: Векторный поиск по эмбеддингам стихов с SIMD-оптимизированным скалярным произведением.
   - **Гибридный ранжировщик**: Reciprocal Rank Fusion (RRF) для объединения результатов ключевых слов и семантики.

3. **Интеллектуальный ассистент «Писарь Соломона»**:
   - Zero-shot системный промпт в формате ChatML для локальной нейросети Qwen2.5-1.5B GGUF через `llama.cpp`.
   - Мгновенный синтез ответов с цитатами из Писания (`ScriptureSynthesizer`).
   - **Предварительный фильтр темы (`TopicGuard`)**: строгая валидация запросов до запуска вычислений — моментальное вежливое отклонение бытовых, математических и отвлечённых вопросов без зависания интерфейса.
   - Порционная пагинация цитат (по 3 цитаты).

## 🏗️ Архитектура проекта

```text
bible-rag/
├── android/               # Мобильное приложение (Kotlin + Jetpack Compose)
│   ├── src/main/kotlin/   # UI, ViewModel, Repository, TopicGuard, RAG Orchestrator
│   └── src/main/assets/   # Предварительно индексированная БД bible.db, ONNX модель
├── cpp/                   # Нативное C++ ядро
│   ├── src/               # bible_rag_engine, simd_math, rrf_ranker, jni_bridge, sqlite3
│   ├── include/           # Заголовочные файлы
│   └── llama.cpp/         # Git-сабмодуль инференса LLM
├── data/                  # Данные Библии
│   └── raw/               # synodal.json (канонический текст Синодального перевода)
└── src/                   # Python-пайплайн подготовки данных
    ├── parser.py          # Парсинг стихов и структурирование
    ├── export_onnx.py     # Квантование модели эмбеддингов в ONNX (int8)
    └── build_mobile_db.py # Создание SQLite FTS5 + векторных таблиц
```

## 🚀 Сборка и запуск

### 1. Клонирование репозитория
```bash
git clone --recursive https://github.com/SolomonJSX/Logos-Bible-RAG-.git
cd bible-rag
```

### 2. Сборка Android приложения
Для сборки требуется Android SDK и JDK 17+:
```bash
cd android
./gradlew installDebug
```

### 3. Запуск Python пайплайна (опционально)
```bash
uv sync
uv run python src/build_mobile_db.py
```
